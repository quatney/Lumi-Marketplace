## flutter_ecommerce_app
A Flutter e-commerce app UI inspired by [Imran's E-commerce App Exploration](https://dribbble.com/shots/10446127-E-commerce-App-Exploration/attachments/2283107?mode=media).

The app includes a product catalog, category navigation, product details, and a shopping cart.

## Run the app
```powershell
flutter pub get
flutter run
```

## Validate
```powershell
flutter analyze
flutter test
```

Product and profile images are bundled in `assets/`.
